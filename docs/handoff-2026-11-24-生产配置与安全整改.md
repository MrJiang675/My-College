## 3. 生产行为说明

- 主配置仍默认 `dev`，因此生产启动必须显式激活 `prod`；仅靠打包不能防止误用 dev。
- `DevAdminInitializer` 保持 `@Profile("dev")`。prod 不创建或刷新固定管理员；管理员必须走受控创建流程。
- 控制器本身已使用 `/api` 前缀，prod **没有**设置 `server.servlet.context-path: /api`，避免实际路径变成 `/api/api/...`。
- CORS 只接受准确的 `Origin`，不允许 `*`；配置值末尾的 `/` 会去除，因为浏览器 `Origin` 头不包含路径或尾斜杠。允许 `GET/POST/PUT/PATCH/DELETE/OPTIONS` 和 `Authorization/Content-Type/Accept/X-Requested-With`，允许凭据。
- CORS 过滤器优先级高于 JWT 过滤器，因此 JWT 直接输出的 401 也会带正确的 CORS 响应头。
- 本机启动器只允许 `prod`，避免误用 dev 管理员初始化器；`local-run.env` 默认使用本地 HTTP 的 `Lax + Secure=false`，公网跨站 HTTPS 再改为 `None + Secure=true`。
- Refresh Cookie 仍为 HttpOnly、path `/`；prod 默认 `SameSite=None; Secure`。真实浏览器是否接受第三方 Cookie 尚未验证。
- 文件上限已统一为 10MB：前端校验/提示、后端 `max-file-size` 均为 10MB；Nginx 请求包络为 12MB，用于容纳 multipart 边界和字段开销。11/25 起上传不纳入 G0，真实 10MB 样例留待完整交付验收。
- prod 使用 `forward-headers-strategy: framework`；后端只能位于受信反向代理之后，不能把 10001 端口无条件暴露公网。

| `MINIO_ENDPOINT` | MinIO 端点 | 必填 |
| `MINIO_ACCESS_KEY` | MinIO Access Key | 必填；秘密 |
| `MINIO_SECRET_KEY` | MinIO Secret Key | 必填；秘密 |
| `MINIO_BUCKET` | MinIO 文档桶 | 必填 |
| `ES_HOST` | Elasticsearch 主机 | 必填 |
| `ES_PORT` | Elasticsearch 端口 | 必填 |

| `ARGUS_RAG_JWT_SECRET` | JWT HMAC 签名密钥 | 必填；强随机秘密 |
| `ZHIPUAI_API_KEY` | 智谱聊天与向量模型凭据 | 必填；秘密 |
| `ARGUS_RAG_AUTH_REFRESH_COOKIE_SAME_SITE` | Refresh Cookie SameSite 策略 | 可选；prod 默认跨站策略 |
| `ARGUS_RAG_AUTH_REFRESH_COOKIE_SECURE` | Refresh Cookie Secure 开关 | 可选；prod 默认开启 |
| `YOUCOM_SEARCH_ENABLED` | 是否启用 You.com 联网检索 | 可选；prod 默认关闭 |
| `YOUCOM_API_KEY` | You.com 联网检索凭据 | 可选；仅启用时需要，秘密 |

DashScope 依赖仍保留供 dev 使用，但 prod/test 已停用其全部自动配置，因此生产不再要求 `DASHSCOPE_API_KEY`。Elasticsearch 当前代码没有用户名/密码或 TLS 配置，不要凭空添加代码不读取的变量；生产应保持内网可达并另行评估认证与 TLS。

本机启动优先级：`DB_PASSWORD` 错误会直接阻止启动；`MINIO_ACCESS_KEY`、`MINIO_SECRET_KEY` 和 `ZHIPUAI_API_KEY` 保留占位符时通常仍可启动，但上传、对象存储、文档处理、向量化和 QA 会失败。`ARGUS_RAG_JWT_SECRET=AUTO_GENERATE_ON_START` 会由脚本生成随机值；若要求重启后登录态仍有效，应改为稳定的私有随机值。
