# Argus 学生工作台｜项目总体介绍

Argus 是面向在校大学生的一站式 AI 工作台。学生可以带着老师的讲义、实验指导书、学院通知或岗位要求进入工作台，用自己的话说出眼前要解决的问题。Argus 会根据任务给出不同的结果：学习时可以回到讲义原文，做实验时可以改变参数、对照曲线，准备申请时可以调出自己过去的项目贡献。一个学生独自使用，就能完成这些事。

## 项目从哪里来

大学里的信息差，常常发生在“已经拿到信息”之后。辅导员转发了一则竞赛通知，学生知道可以报名，却不知道自己的年级是否符合要求，更不知道获奖能否按本学院的细则认定。老师发了几十页课件，考前最难的可能只是找到某个公式成立的条件。到了申请实习的时候，去年做过的课程设计还记得，自己具体负责什么、成果放在哪里，却要翻遍聊天记录才能想起来。

Argus 把这些具体困难放在同一个工作台里解决。学生填写学校、学院、专业和年级，可以同时准备考试、做项目、关注机会和申请实习。每个板块保留自己的材料、对话和草稿，切换任务后仍能回来接着做。在既有团队里学习或做项目的学生，也可以使用协作小组共享获授权的课程资料。

## AI 在工作台里做什么

专业实践最能说明这种设计。学生上传一份指导书，里面写着电阻 12 kΩ、电容 50 μF、电源 6 V，再说“按这份指导书生成充电实验”。AI 提取条件，工作台用确定的计算模型画出曲线。学生接着说“电阻改成原来的两倍，其他不变”，两条曲线就能放在一起比较。时间常数从 0.6 秒变成 1.2 秒，而电源和电容保持原值。这条流程已用真实模型和自编指导书完成验收。

换一个专业，同一个入口可以承接不同任务。新闻专业学生提供采访原话和拟写的报道，工作台可以逐项呈现原句、报道表述与核实意见。跨专业适配体现在材料、提问和交互方式上。目前可计算的实验覆盖理想 RC 充电与悬臂梁静载；一个学科的具体模型需要逐项实现和验证。

## 为什么把这些事放在一起

一名学生今天在“我的项目”记录了“我负责传感器标定”，并附上实验报告的位置。几个月后，他可以在“升学就业”勾选这段经历，请助手对照岗位要求整理申请材料。在另一些任务里，学生最需要的是保留依据：课程答案可以回看检索到的原文，校园机会可以回到发布单位核对，缺少综测认定目录时知道还该找哪份文件。

项目采用 Vue 和 TypeScript 构建前端，以 Java 21 和 Spring Boot 承载登录、资料权限、问答、实验任务与个人记录。知识库通过 MinIO 保存文件，结合 Elasticsearch 和 PostgreSQL/pgvector 检索相关片段。账号、课程资料、自编讲义问答和实验追问已在本机真实服务上联通。各板块的入口、用法和当前覆盖范围见[板块功能说明](features.md)。
